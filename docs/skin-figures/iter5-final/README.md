## 最终设计

- 仪器：白瓷机箱、内凹仪表与紧凑导轨；深色反光收敛。
- 编辑：薄线、连续排版与大数字；减少重复标题。
- 活水：以改进版 L2-3 HTML 的水箱剖面为依据，恢复细水线、斜射光、下沉微粒、接续线与单色岩芯沉积层。真实记录可点开原文，分类可进入对应列表。
- 三套保持蓝白整体，仅分类与重点组件放开彩色。日志蓝、笔记绿、反思紫、偏好琥珀；图表、图例和记录标记同义同色。深色另配可读的浅亮分类色。
- 浅色、深色、跟随宿主独立于皮肤选择；升级迁移旧 `dam-skin-theme` 偏好。
