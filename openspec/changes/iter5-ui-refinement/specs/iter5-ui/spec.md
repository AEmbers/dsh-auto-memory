# Compact memory workspace

## Requirements

- The refinement SHALL preserve the established light palette, real APIs, default classic skin and settings draft protections.
- The memory list SHALL use compact rows without shrinking document text or hiding full source paths. Narrow content containers SHALL use a single column and reachable detail selection.
- The reader SHALL never display the previous file under a newly selected title or accept late results from a different session/workspace identity.
- The home page SHALL retain recent records, category entry points, actual context measurement and calendar actions. Total and subset file counts SHALL be distinguished. Automatic-memory counters SHALL not claim an unverified date.
- The generated bundle SHALL match sources on both LF and CRLF checkouts. Shared overlay tokens SHALL exclude page layout declarations.
- Validation SHALL distinguish reference-preview evidence, isolated real-host interactions, component scope tests and upstream CI failures.
